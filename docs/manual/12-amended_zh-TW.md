# 12. 修正申告

已申報年度快照的建立、差異偵測、沖銷傳票的做法、提交步驟。

**Language**: [日本語](12-amended.md) | [English](12-amended_en.md) | **繁體中文**

> **讀完這章你能做到**
> - 把已申報的年度鎖定、保留「申報當下的快照」
> - 之後發現錯誤時，查看差異並加上沖銷傳票
> - 整理修正申告書提交需要的資訊
>
> **前提**：[06. 報表](06-reports_zh-TW.md) 該年度已鎖定（[§ 8](06-reports_zh-TW.md#8-年度鎖定已申報)）。

## 1. 什麼是修正申告

確定申告書提交**之後**才發現稅額計算或所得計算有錯：

- **稅額申報太少**（要補繳）→ **修正申告**
- **稅額申報太多**（可退稅）→ **更正の請求**

兩者在 e-Tax 側的提交樣式・處理方式不同。aoiko 側的作業兩種都差不多（改資料、看差異），但 e-Tax 側的手續不同。

> 本工具不直接支援申告書的建立・提交。只提供差異偵測跟「什麼變了」的整理。

## 2. 已申報快照

[06. 報表 § 8](06-reports_zh-TW.md#8-年度鎖定已申報) 按 「**標記為已申報並鎖定**」 時，aoiko 把當下的：

- 月別銷貨・損益計算書・資產負債表・消費稅（若已設定）這 4 種報表資料

…存成**快照**，儲存到 IndexedDB。這就是申告書提交時內容的快照。

> 申告書正本（紙本或 e-Tax 提交資料的已儲存檔案）**請務必另外儲存**。aoiko 快照以數字為主，不涵蓋申告書本體（個人資訊・所得控除 等）的內容。

## 3. 修正工作流

### 3-1. 解除鎖定

要變更設定，必須先解鎖。

1. 報表 → 選該年度
2. 🔒 已申報徽章旁邊按 「**解除鎖定**」
3. 確認後年度變解鎖狀態

> 快照**不會被刪除，會保留下來**（重要）。

### 3-2. 加入差異對象

解鎖後：

- 傳票 **追加**（漏的經費、漏申告的銷貨 等）→ 照常用 [02. 建立傳票](02-journal_zh-TW.md)
- 傳票 **訂正**（金額或科目錯）→ [02. § 3 沖銷傳票](02-journal_zh-TW.md#3-沖銷傳票--改錯) 沖銷 → 建立正確新傳票
- 固定資產 **重新登錄**（耐用年數修正、報廢處理 等）→ [08. 折舊](08-depreciation_zh-TW.md)

> 沖銷傳票的 `description` 寫清楚（例：「2026 年分修正申告 — 銷貨漏申告追加（XXX 公司）」）。之後差異原因要看得出來。

### 3-3. 差異確認

加入沖銷傳票後，報表畫面上與概況區塊分開的**修正申告差異專用面板**會：

- 顯示目前值（修正後）與快照的**差**
- 各項目 `修改前 → 修改後` 並排
- 主要變化（損益計算書所得增減、資產負債表餘額變動）摘要

> 差異和你預期的一致嗎？務必確認。如果預期之外的地方有變動，請檢查相關傳票。

### 3-4. e-Tax 側建立修正申告書

aoiko 上數字固定後：

1. 開啟 e-Tax 軟體（下載版） 或 確定申告書等作成コーナー（所得稅的修正申告 WEB 版不支援）
2. 「**修正申告書作成**」 選單（正式名稱依當年度 e-Tax UI 而定）
3. **當初申告（決算書〔青色申告決算書／収支内訳書〕→ 確定申告書）的值**：把 aoiko 再次輸出的 `.xtx` 組み込み到下載版，或在作成コーナー手動輸入
4. 「**正確的金額**」欄用修正後的數字輸入
5. 差異由 e-Tax 側自動計算，延滯稅・加算稅的概算也會顯示
6. 提交（電子）

> aoiko 的 `.xtx` 再次輸出（[10. `.xtx` 輸出](10-xtx-export_zh-TW.md)）是照當下的帳簿狀態直接組出來的，IT 部的 `SHINKOKU_KBN`（申告種類）一律輸出「確定」，不會切換成修正申告用的種別。因此再次輸出的 `.xtx` 請當作「確認修正後正確數字」的參考資料，修正申告本身的提交資料請用 e-Tax 側的修正申告書建立選單。

### 3-5. 提交後重新鎖定

提交修正申告書之後：

1. 報表 → 該年度 → 「**標記為已申報並鎖定**」 重新鎖
2. **用新快照覆蓋**（修正後狀態成為新的「已申報」值）

> 舊快照不會被刪除，會以 `superseded`（已被取代）的狀態保留。事後想比較「修正申告前與修正申告後」時有基準可查，但申告書正本（提交資料）仍請另外儲存。

## 4. 常見情境

### 情境 A：銷貨漏記

```
發現：2026 年分確定申告提交後，才注意到漏記了 12 月份的銷貨 100,000 圓
```

1. 解鎖
2. 加傳票：`借方 1320 未収入金 100,000 / 貸方 4110 売上高 100,000`（日期 2026-12-31 等）
3. 確認差異：所得 +100,000
4. e-Tax 修正申告 → 補繳
5. 重新鎖定

### 情境 B：經費重複列入

```
發現：同一筆 AWS 費用 5,000 圓，被 CSV 匯入和手動傳票各登錄了一次
```

1. 解鎖
2. 從 [03. CSV § 5](03-csv-import_zh-TW.md#5-匯入紀錄與整批沖銷) 沖銷該批次、或把手動那筆沖銷
3. 確認差異：經費 -5,000、所得 +5,000
4. e-Tax 修正申告 → 補繳
5. 重新鎖定

### 情境 C：固定資產折舊漏登

```
發現：MacBook 當年度的折舊傳票忘了產生（耐用年數 4 年本身沒錯）
```

1. 解鎖
2. 固定資產 → 該資產確認 → 確認取得日・耐用年數・科目沒有錯誤
3. 用 [08. § 3](08-depreciation_zh-TW.md#3-年末產生折舊傳票) 產生當年度的折舊傳票
4. 確認差異
5. 屬於漏記費用（稅額申報過多），所以在 e-Tax 上提交「**更正の請求**」
6. 重新鎖定

### 情境 D：所得控除修正（不需要沖銷傳票）

```
發現：忘了申報醫療費扣除
```

在 e-Tax 側直接做「**更正の請求**」。事業所得側沒變化，所以不需要沖銷傳票或解除鎖定。有在用 aoiko 的[所得控除畫面](14-income-deductions_zh-TW.md)（試算・`.xtx` 帶入用，不在年度鎖定範圍內）的話，順手把畫面的值也改掉，保持紀錄一致。

## 5. 期限與注意

### 修正申告提交期限

- **修正申告**（補繳）：在依第 24 條（更正）規定所做的更正確定之前，都可以提交（國稅通則法 19 條 1 項）。發現得越早提交越好（延滯稅每天都在增加）
- **更正の請求**（退稅）：原則從申告期限算起 **5 年內**

### 加算稅・延滯稅

- 修正申告會被加課**過少申告加算稅**（10% 或 15%）與**延滯稅**（年率會變動）
- 在稅務署調查通知前自願修正的話，不會被課過少申告加算稅（國稅通則法 65 條 6 項）；反過來，沒有提示・提交帳簿等情形則會加重加算稅（同條 4 項，加重的比例為 10% 或 5%）
- 細節請向稅理士・稅務署確認

### 帳簿保存

- 青色申告者的帳簿要保存 7 年（所得稅法施行規則 63 條 1 項 1 號）。起算日是帳簿結帳日所屬年度的**次年 3 月 15 日的次日**（同條 4 項）。修正申告後的沖銷傳票也屬於這套帳簿的一部分，同樣要保存
- 修正前後的差異在 aoiko 內會以「沖銷傳票紀錄」的形式保留，這些也要保存
- 請用備份（[11. 備份與還原](11-backup_zh-TW.md)）妥善保管
