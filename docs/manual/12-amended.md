# 12. 修正申告

申告済年度のスナップショット作成、差分検出、修正仕訳の入れ方、提出手順。

**Language**: **日本語** | [English](12-amended_en.md) | [繁體中文](12-amended_zh-TW.md)

> **この章を読み終えたら出来ること**
> - 申告済の年度をロックして「申告時点のスナップショット」を保持できる
> - 後から間違いに気付いた時、差分を見て修正仕訳を入れられる
> - 修正申告書の提出に必要な情報を整理できる
>
> **前提**：[06. レポート](06-reports.md) で当該年度をロック済（[§ 8](06-reports.md#8-年度ロック申告済み)）。

## 1. 修正申告とは

確定申告書を提出した **後で**、税額計算や所得計算に誤りがあったと判明した場合：

- **税額を過少に申告していた**（追加納税が必要）→ **修正申告**
- **税額を過大に申告していた**（還付の権利）→ **更正の請求**

両者は提出様式・処理が異なります。aoiko 側の作業は両者ともほぼ同じ（変更を入れて差分を出す）ですが、e-Tax 側の手続が異なります。

> 本ツールは申告書の作成・提出を直接は支援しません。差分検出と「何が変わったか」の整理のみ提供します。

## 2. 申告済スナップショット

[06. レポート § 8](06-reports.md#8-年度ロック申告済み) で 「**申告済みとしてロック**」 を実行すると、aoiko はその時点の：

- 月別売上・損益計算書（PL）・貸借対照表（BS）・消費税（設定済みの場合）の 4 種類のレポートデータ

…を **snapshot** として IndexedDB に保存します。これが申告書提出時に書いた内容のスナップショット。

> 申告書原本（紙 or e-Tax 提出データの控え）は **必ず別途保管**してください。aoiko の snapshot は数値ベースで、申告書本体（個人情報・所得控除等）まではカバーしません。

## 3. 修正のワークフロー

### 3-1. ロック解除

設定変更を加えるためロックを解く必要があります。

1. レポート → 該当年度を選択
2. 🔒 申告済みバッジ横の 「**ロック解除**」 をクリック
3. 確認後、年度がロック解除状態に

> snapshot は削除されず保持されます（重要）。

### 3-2. 差分の対象を入れる

ロック解除後：

- 仕訳の **追加**（漏れていた経費、申告漏れの売上 等）→ 通常通り [02. 仕訳の作成](02-journal.md)
- 仕訳の **訂正**（誤った金額・科目）→ [02. § 3 訂正仕訳](02-journal.md#3-訂正仕訳修正仕訳--間違いを正す) で打ち消し → 正しい仕訳を新規追加
- 固定資産の **再登録**（耐用年数の修正、廃棄処理 等）→ [08. 減価償却](08-depreciation.md)

> 修正仕訳の `description` は分かりやすく書く（例：「2026 年分修正申告 — 売上漏れ追加（XXX 社）」）。後で差分の理由が分かるように。

### 3-3. 差分の確認

修正仕訳を入れた後、レポート画面の **修正申告の差分専用パネル**（概況ブロックとは別）を見ると：

- 現在値（修正後）と snapshot の **差** が表示される
- 各項目の `Before → After` が並ぶ
- 主な変化（PL の所得増減、BS の残高変化）の要約

> 差分が想定どおりか必ず確認。意図しない箇所が変わっていたら関連仕訳を見直す。

### 3-4. e-Tax 側で修正申告書を作成

aoiko 上で数値が固まったら：

1. e-Taxソフト(ダウンロード版) または 確定申告書等作成コーナー を開く（所得税の修正申告は WEB 版 非対応）
2. 「**修正申告書の作成**」 メニュー（正確な名称は当年度の e-Tax UI に依存）
3. **当初申告（決算書〔青色申告決算書／収支内訳書〕→ 確定申告書）の値**は、aoiko の `.xtx` 再出力をダウンロード版に組み込むか、作成コーナーへ手入力
4. 「**正しい金額**」 を修正後の数値で入力
5. 差分計算は e-Tax 側で自動。延滞税・加算税の概算も表示される
6. 提出（電子）

> aoiko の `.xtx` 再出力（[10. `.xtx` 出力](10-xtx-export.md)）は、その時点の帳簿状態でそのまま組み立てられ、IT 部の `SHINKOKU_KBN`（申告の種類）は常に「確定」で出力されます。修正申告用の種別には切り替わらないため、再出力した `.xtx` は「修正後の正しい決算書の値を確認する参考資料」として使い、修正申告そのものの提出データとしては e-Tax 側の修正申告書作成メニューを使ってください。

### 3-5. 提出後の再ロック

修正申告書を提出したら：

1. レポート → 該当年度 → 「**申告済みとしてロック**」 で再ロック
2. **新しい snapshot で上書き**される（修正後の状態が「申告済み」値に）

> 古い snapshot は削除されず、`superseded`（差替済み）として保持されます。「修正申告前 vs 修正申告後」の差分を後から見返す基準になりますが、申告書原本（提出データ）は引き続き別途保管してください。

## 4. ありがちなケース

### ケース A：売上の計上漏れ

```
発覚：2026 年分の確定申告提出後、12 月分の売上 100,000 円が漏れていた
```

1. ロック解除
2. 仕訳追加：`借方 1320 未収入金 100,000 / 貸方 4110 売上高 100,000`（日付 2026-12-31 等）
3. 差分確認：所得 +100,000
4. e-Tax で修正申告 → 追加納税
5. 再ロック

### ケース B：経費の二重計上

```
発覚：同じ AWS 費用 5,000 円が CSV 取込と手動仕訳で 2 回入っていた
```

1. ロック解除
2. [03. CSV § 5](03-csv-import.md#5-取込履歴とバッチ訂正) で該当バッチを reverse、または手動の方を訂正仕訳で打消し
3. 差分確認：経費 -5,000、所得 +5,000
4. e-Tax で修正申告 → 追加納税
5. 再ロック

### ケース C：固定資産の減価償却計上漏れ

```
発覚：MacBook の当年度分の減価償却仕訳を生成し忘れていた（耐用年数 4 年自体は正しい）
```

1. ロック解除
2. 固定資産 → 該当資産を確認 → 取得日・耐用年数・科目に誤りが無いことを確認
3. [08. § 3](08-depreciation.md#3-年末に減価償却仕訳を生成) で当年度分の減価償却仕訳を生成
4. 差分確認
5. 経費計上漏れ（税額の申告超過）なので e-Tax で更正の請求
6. 再ロック

### ケース D：所得控除の修正（仕訳の訂正は不要）

```
発覚：医療費控除を入れ忘れていた
```

e-Tax 側で 「**更正の請求**」 を直接行う。事業所得側に変更が無いため、仕訳の訂正・ロック解除は不要。aoiko の [所得控除画面](14-income-deductions.md)（試算・`.xtx` 転記用、年度ロックの対象外）を使っている場合は、記録を最新に保つために画面の値も直しておくとよい。

## 5. 期限と注意

### 修正申告の提出期限

- **修正申告**（追加納税）：第 24 条（更正）の規定による更正があるまでは提出できます（国税通則法 19 条 1 項）。気付いたら早く提出（延滞税が日々増える）
- **更正の請求**（還付）：原則、申告期限から **5 年以内**

### 加算税・延滞税

- 修正申告の場合、**過少申告加算税**（10% または 15%）と **延滞税**（年率変動）が課される可能性
- 税務署の調査通知前に自発的に修正した場合、過少申告加算税は課されません（国税通則法 65 条 6 項）。逆に、帳簿の提示・提出をしなかった場合等は加算税が加重されます（同条 4 項、割合は百分の十または百分の五）
- 詳細は税理士・税務署に確認

### 帳簿保存

- 青色申告者の帳簿は 7 年間保存対象（所得税法施行規則 63 条 1 項 1 号）。起算日は帳簿を閉鎖した日の属する年の **翌年 3 月 15 日の翌日**（同条 4 項）。修正申告後の修正仕訳もこの帳簿の一部として保存対象になります
- 修正前後の差分は aoiko 内では「訂正仕訳の履歴」として残るので、これも保存対象
- バックアップ（[11. バックアップと復元](11-backup.md)）でしっかり保管
